Azure Databricks Medallion Lakehouse & Unity Catalog

Bronze Layer (Raw Ingestion)

Streams raw JSON/CSV datasets from ADLS Gen2 using PySpark **Auto Loader (`cloudFiles`)** with schema evolution and metadata tracking.

Silver Layer (Cleansed Data)

Applies schema enforcement, data type casting, null handling, and row deduplication to build clean Delta tables.

Gold Layer (Aggregated Analytics)

Aggregates business KPIs optimized with **`OPTIMIZE`** and **Z-Ordering** for high-speed Power BI reporting.

Technical Architecture & Security Specs

  • — Unity Catalog Governance: Organized tables into a 3-tier namespace (`catalog.schema.table`) for fine-grained access control.
  • — OAuth 2.0 Security: Authenticated ADLS Gen2 external locations using Azure Service Principals and Key Vault secrets.
  • — ACID Transactions & Time Travel: Leveraged Delta Lake transaction logs for data auditing and fast rollbacks.
  • — Workflow Automation: Automated multi-notebook dependency execution using Databricks Jobs & Workflows.

# Streaming Ingestion into Unity Catalog Bronze Layer via Auto Loader
from pyspark.sql.functions import current_timestamp

raw_stream_df = (spark.readStream
    .format("cloudFiles")
    .option("cloudFiles.format", "json")
    .option("cloudFiles.schemaLocation", "abfss://schema@storage.dfs.core.windows.net/checkpoints")
    .load("abfss://raw@storage.dfs.core.windows.net/ingest/"))

processed_df = raw_stream_df.withColumn("ingestion_time", current_timestamp())

(processed_df.writeStream
    .format("delta")
    .outputMode("append")
    .option("checkpointLocation", "abfss://checkpoints@storage.dfs.core.windows.net/bronze_checkpoints")
    .toTable("main_catalog.bronze_db.raw_telemetry_events"))
